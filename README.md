# Ransomware-Keylogger-DIO
Criação de códigos maliciosos em ambiente controlado para fins educacionais e informativos.

## 🏴 **SOBRE O PROJETO** 🏴
Nesse projeto, documentarei a respeito do desenvolvimento de malwares, como Keylogger e Ransomware, em Python.
Embora eu não tivesse experiência prévia em Python, consegui desenvolver todos os códigos com base nas instruções
compartilhadas pela Professora Isadora Ferrão durante as aulas da DIO. O foco não é atacar, e sim entender como
esses ataques funcionam, de forma básica e intuitiva.

## ❗ **AVISO LEGAL** ❗
Todos os testes foram executados em ambiente controlado, sem prejudicar terceiros; é proibido utilizar este
conhecimento para comprometer a privacidade de alguém (art. 154-A). Este repositório tem finalidade exclusivamente
educacional.

## 🧪 **OBJETIVOS** 🧪
1-Compreender o funcionamento de malwares;
2-Desenvolver familiaridade com Python e suas bibliotecas;
3-Reconhecer arquivos potencialmente perigosos;
4-Aprender a desenvolver a partir de uma base sólida;
